# Minecraft Debug Shortcuts

Справочник отладочных сочетаний клавиш Minecraft: Java Edition (актуально для 1.20+, часть комбинаций отмечена как устаревшая или новая).

Все комбинации `F3 + X` выполняются так: **зажать F3**, нажать вторую клавишу, отпустить обе. Экран отладки при этом появляться/исчезать не будет.

---

## Экран отладки (F3)

| Сочетание | Действие |
|---|---|
| `F3` | Показать/скрыть экран отладки (координаты, FPS, биом, свет, память) |
| `Shift + F3` | Экран отладки + профилировщик (круговая диаграмма нагрузки) |
| `Alt + F3` | Экран отладки + график времени кадра (frame time graph) |
| `F3 + Q` | Показать список всех доступных `F3`-комбинаций прямо в чате |
| `F3 + Esc` | Пауза без меню паузы (работает при выключенном «Pause on Lost Focus») |

## Отрисовка и мир

| Сочетание | Действие |
|---|---|
| `F3 + A` | Перезагрузить все чанки (пересобрать графику мира) |
| `F3 + B` | Показать/скрыть хитбоксы сущностей и направление взгляда |
| `F3 + G` | Показать/скрыть границы чанков |
| `F3 + T` | Перезагрузить ресурспаки: текстуры, модели, звуки, шейдеры |
| `F3 + S` | Перезагрузить только звуки *(удалено, объединено с `F3 + T`)* |
| `F3 + F` / `F3 + Shift + F` | Увеличить / уменьшить дальность прорисовки *(устарело)* |

## Данные и буфер обмена

| Сочетание | Действие |
|---|---|
| `F3 + C` | Скопировать координаты как готовую команду `/tp` |
| `F3 + C` (удерживать 6 сек) | Принудительный краш игры (`Manually triggered debug crash`) |
| `F3 + I` | Скопировать NBT-данные блока/сущности под прицелом *(нужен креатив + права оператора)* |
| `F3 + H` | Расширенные подсказки предметов: ID, прочность, теги, зачарования |
| `F3 + D` | Очистить историю чата |

## Игровой процесс и профилирование

| Сочетание | Действие |
|---|---|
| `F3 + N` | Переключение между режимами «Творческий» и «Наблюдатель» *(нужны читы)* |
| `F3 + P` | Вкл/выкл «Pause on Lost Focus» — пауза при потере фокуса окна |
| `F3 + L` | Записать 10-секундный снимок профилирования в `debug/` |
| `F3 + 1` | Свернуть/развернуть секции экрана отладки *(1.21.2+)* |
| `F3 + 3` | График времени кадра / FPS *(1.21.2+)* |
| `F3 + 4` | Переключить графики профилировщика *(1.21.2+)* |

## Общие клавиши, полезные при отладке

| Клавиша | Действие |
|---|---|
| `F1` | Скрыть/показать HUD (интерфейс) |
| `F2` | Скриншот (в `.minecraft/screenshots`) |
| `F5` | Смена вида от 3-го лица |
| `F11` | Полноэкранный режим |
| `Ctrl + B` | Вкл/выкл рассказчика (Narrator) |
| `Shift + ЛКМ` по слоту | Быстрое перемещение стака |
| `Ctrl + ЛКМ` по предмету в креативе | Взять полный стак |
| `Ctrl + ПКМ` по блоку в креативе | Копировать блок вместе с NBT (pick block с данными) |
| `Средняя кнопка мыши` | Pick block — взять блок под прицелом |

## Отладочные инструменты и команды

| Инструмент / команда | Назначение |
|---|---|
| `/debug start` \| `stop` \| `function` | Запись сессии профилирования сервера в `debug/` |
| `/give @s minecraft:debug_stick` | Debug Stick: ПКМ меняет значение свойства блока, ЛКМ выбирает свойство |
| `minecraft:light` (Light Block) | Невидимый источник света для отладки освещения |
| `minecraft:structure_block` | Сохранение/загрузка структур, отладочный режим |
| `/data get entity @s` | Просмотр NBT игрока или сущности |
| `/tick freeze` \| `step` \| `rate` | Заморозка и пошаговое выполнение тиков *(1.20.2+)* |
| `/gamerule` | Правила мира: `doDaylightCycle`, `keepInventory`, `sendCommandFeedback` и др. |
| `Debug World` (Shift + «Тип мира» при создании) | Мир со всеми блоками и их состояниями |

---

## Заметки

- Комбинации `F3 + …` — только Java Edition. В Bedrock Edition отладочный экран вызывается через настройки/`F3` частично и набор команд отличается.
- Если `F3` перехватывается системой или ноутбуком, попробуйте `Fn + F3`.
- Часть комбинаций зависит от версии — точный список для вашей сборки всегда даёт `F3 + Q`.
